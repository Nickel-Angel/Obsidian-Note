# `<form>` 元素
所有表单都以 `form` 开头。
```html
<form action="/myhandling-form-page" method="post">...</form>
```
`action` 是表单收集到的数据在提交时应该发送到的位置（URL）；
`method` 用于定义了发送数据的方法。
# `<label>`、`<input>` 和 `<textarea>` 元素
`<input>` 是单行文本字段；
`<textarea>` 是多行文本字段。
`<label>` 的 `for` 属性就是对应的表单控件的 id

```html
<form action="myhandling-form-page" methon="post">
	<ul>
		<li>
			<label for="name">Name:</label>
			<input type="text" id="name" name="user_name" />
		</li>
		<li>
			<label for="mail">E-mail:</label>
			<input type="email" id="mail" name="user_mail" />
		</li>
		<li>
			<label for="msg">Message:</label>
			<textarea id="msg" name="user_message"></textarea>
		</li>
	</ul>
</form>
```
注意 `<input>` 和 `<textarea>` 设置默认值的方式：
```html
<input type="text" value="default text" />
<textarea>default text</textarea>
```
# `<button>` 元素
按钮有三种属性：
* `sumbit`：（默认值）会将表单数据发送到 `<form>` 元素的 `action` 属性定义的网页；
* `reset`：将所有表单小部件重置为默认值；
* `button`：自定义按钮，没有默认行为，需要 js 改写逻辑。
```html
<button type="submit">Send your message</button>
```
