* 好的设计原则
	* 以用户为中心
	* 具有广泛适配性的（即使有特定的用户群体，他们的偏好可能也各不相同）
	* 易懂与无缝（用户使用时不会感到困惑）
- UI / UX
	- User Interface
	- User Experience
- UI Elements
	- 字体
		- Serif 增加正式感，Sans-serif 增加现代感。
		- 善用标题等工具增加层次感
		- 加粗，斜体等区分内容重要性
		- 移动端适合 >12px 的字体，而电脑端适合 >15px 的字体
	- 颜色
		- 使用反色
		- 颜色和谐程度（单色、互补色、相近色）
		- 多使用中性色，可以使得你的主题颜色更加突出
		- Less is more
		- 60-30-10 原则，60% 的主色调，30% 的中性色，10% 的强调色
		- create your own rule, balance is important
	- 空隙
	- 卡片
	- 选项卡
	- 按钮
	- 表单
- 设计师的职责
	- 设计网站的图像和用途
	- 设计用户操作流程
	- 对用户体验进行调研
	- 作为用户和开发者之间沟通的桥梁
